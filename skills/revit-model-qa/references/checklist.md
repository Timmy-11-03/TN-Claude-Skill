# Revit model QA checklist

Add or remove items to match your project standards.

## Naming
- [ ] Views follow the convention (for example `[Level]_[Discipline]_[Description]`)
- [ ] Sheet numbers and names match the drawing list
- [ ] Family names have no odd characters and no suffixes such as `(1)` or `Copy`

## Data
- [ ] Required parameters (Mark, Type Comments, Phase, ...) are not empty
- [ ] Rooms have a Name and Number and are not Not Placed / Redundant

## Organization
- [ ] No unused views outside sheets (except working views)
- [ ] Worksets follow the standard; nothing left on the default Workset1
- [ ] No unused links or imported CAD files
